# 유흥 동문회 레크리에이션 진행 사이트

PPT(진행자용 초안)를 그대로 웹페이지로 옮긴 레크리에이션 진행용 사이트입니다.
서버/빌드 없이 HTML/CSS/JS만으로 동작하므로 GitHub Pages에 그대로 올리면 됩니다.

## 구성

| 섹션 | 기능 |
| --- | --- |
| 시작 / 진행 순서 / 팀 구성 | 오프닝, 10단계 타임테이블(클릭하면 이동), 팀 이름 즉석 수정 |
| GAME 01 노래 믹스 퀴즈 | 문제별 음원 재생, 정답 공개, 연도/난이도 필터, 팀 점수 입력 |
| GAME 02 이심전심 | 제시어 랜덤 뽑기(중복 없음), "하나, 둘, 셋!" 카운트다운, 즉석 제시어 추가 |
| MID GAME A4 퍼즐 | 타이머(5/10/15분), 우승자 메모 |
| GAME 03 몸으로 말해요 | 주제/팀/시간 선택, 단어 블러 처리, 정답/패스 카운트, 점수판 반영 |
| GAME 04 텔레파시 | 팀별 답변 입력 시 점수 자동 계산(팀 수+1 - 답변 종류 수), 점수판 반영 |
| 휴식 & 중간 집계 | 실시간 점수판 + 휴식 타이머 |
| FINAL 보물찾기 | 쪽지 종류 안내, +1/+3/+5 점수 입력, 타이머 |
| 최종 집계 & 룰렛 | 순위 발표(꼴찌부터 공개), 꼴찌 팀원 자동 룰렛 |
| 최종 미션 / 마무리 | Option A/B 안내, 엔딩 화면 |

화면 오른쪽 아래 **점수판** 버튼은 어느 화면에서든 전체 점수를 보여주고, 직접 수정/되돌리기/초기화가 가능합니다.
점수는 브라우저(localStorage)에 자동 저장되므로 새로고침해도 유지됩니다.
**진행자 한 대의 기기로 계속 진행**하는 것을 전제로 합니다(기기 간 실시간 동기화는 없음).

키보드 `←` / `→` 로 이전/다음 섹션으로 이동할 수 있습니다.

## 내용 수정하기 (코드를 몰라도 가능)

수정은 전부 **`js/data.js`** 한 파일에서 합니다. 따옴표 안의 글자만 바꾸세요.

| 바꾸고 싶은 것 | `data.js`의 위치 |
| --- | --- |
| 노래 퀴즈 음원/정답/난이도/연도 | `song.rounds` |
| 난이도별 점수 | `song.levelPoints` |
| 이심전심 제시어 | `simsim.words` |
| 몸으로 말해요 주제/단어 | `charades.categories` |
| 몸으로 말해요 제한 시간 | `charades.presetSeconds`, `charades.defaultSeconds` |
| 텔레파시 제시어 | `telepathy.prompts` |
| 팀 이름/인원/팀원/색 | `teams` |
| 진행 순서/시간 | `agenda.items` |
| 최종 미션 문구 | `mission` |
| 오프닝/엔딩 문구 | `event` |

### 노래 퀴즈 음원 넣기

1. 음원 파일(mp3 권장)을 `assets/audio/` 폴더에 넣습니다. 예: `assets/audio/q1.mp3`
2. `data.js`의 해당 문제에 경로를 적습니다.

```js
{ level: "하", year: "2000년대", audio: "assets/audio/q1.mp3",
  songs: ["곡 제목 A - 가수", "곡 제목 B - 가수", "곡 제목 C - 가수"] },
```

문제를 늘리거나 줄이려면 `{ ... },` 한 덩어리를 복사하거나 지우면 됩니다.
저작권이 있는 음원은 비공개 저장소(Private)에 두거나, 행사 당일 기기에서 직접 파일로 재생하는 것을 권장합니다.
GitHub Pages는 저장소가 Private여도 사이트는 공개될 수 있으니 주의하세요.

### 팀원 이름 넣기 (룰렛용)

```js
{ name: "A팀", size: 5, members: ["김철수", "이영희", "박민수", "최지우", "정하늘"], color: "#ff6b8b" },
```

`members`를 비워두면 룰렛에 "A팀 1번, A팀 2번..."으로 표시됩니다.
룰렛 화면의 후보 칸은 행사 중에도 직접 고칠 수 있습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다. (예: `yuheung-recreation`)
2. 이 폴더의 파일 전체를 저장소 루트에 올립니다. (`index.html`이 맨 위에 있어야 함)
3. 저장소 **Settings > Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 선택하고 Save.
4. 1~2분 뒤 `https://<내 아이디>.github.io/<저장소 이름>/` 주소로 접속됩니다.

내용을 고친 뒤에는 `data.js`를 다시 커밋하면 자동으로 반영됩니다.
(브라우저에서 바로 안 바뀌면 `Ctrl + Shift + R`로 새로고침)

## 로컬에서 확인하기

`index.html`을 더블클릭해서 열어도 동작합니다.
음원 재생까지 확인하려면 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속.

## 파일 구조

```
index.html          페이지 뼈대
css/style.css       디자인
js/data.js          콘텐츠 설정 (여기만 수정)
js/app.js           동작 코드
assets/audio/       노래 퀴즈 음원
```

## 참고

- 폰트(Pretendard, Black Han Sans)는 인터넷에서 불러옵니다. 오프라인 환경이면 기본 폰트로 대체됩니다.
- 텔레파시는 "팀당 답변 1개" 기준으로 계산합니다. 조별 답변을 따로 인정하려면 PPT 메모대로 규칙을 먼저 확정해 주세요.
